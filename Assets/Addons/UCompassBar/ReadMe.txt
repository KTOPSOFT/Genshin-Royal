MFPS Integration:

For integrate to MFPS 2.0 simply:

• Go to (Toolbar)MFPS -> Addons -> CompassBar -> Setup Players
• Then open a room/map scene (you have to do in each map scene) and then go to
  MFPS -> Addons -> CompassBar -> Add Compass -> In opened window select which compass style you want to integrate in this scene.
• Ready!
